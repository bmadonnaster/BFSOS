# BFSOS r500 Offline Audit — 2026-10-20

## Reproduced cause

The ISO builder's explicit `iso_packages` contains `fastfetch`. `ports/opt/fastfetch/Pkgfile` made `imagemagick` required, whose Pkgfile makes `ffmpeg` required, and FFmpeg makes both `lame` and `alsa-lib` required. That dependency chain is sufficient to explain unwanted multimedia ports being pulled into the ISO dependency closure. It does not imply all ALSA libraries are unnecessary on a desktop ISO.

Original calculated mandatory closure: 378 reachable names. After moving ImageMagick to Fastfetch's optional list: 122 reachable names. Counts are based on first-line `# Depends on:` declarations and the actual hard-coded ISO seeds plus separately selected kernel and gobject-introspection; not final installed binary sizes. Some package names lack an available port and prt-get semantics may differ. Note the builder runs `sysup` ahead of seed installation.

## Changes

- `ports/opt/fastfetch/Pkgfile`: release=3; ImageMagick optional, image-logo configured OFF unless ImageMagick executable and MagickCore pkg-config data exist; the text logo remains packaged.
- `ports/opt/lame/Pkgfile`: release=3; error propagation for configure, make, install. The LAME build failure's actual root cause is unverified.
- `scripts/tests/test-r500-iso-deps.py`: dependency-closure regression; PASS offline.
- `scripts/tests/test-r493-targeted-fixes.py`: a historical assertion about Fastfetch's forced ON mode is updated to accept the r500 conditional selection; that suite still fails on an independent existing Bash flag assertion.
