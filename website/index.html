Introduction

BFSOS is an x86_64 source-built Linux distribution maintained by Brian Madonna. It combines an LFS/MLFS-style bootstrap with CRUX pkgutils/ports, prt-get, systemd, Dracut, GRUB, and a Dialog-based installer.

Current release: 0.9.0

Install

Use the live ISO for the guided installer, or use the base/rootfs archive for a bootstrap/manual workflow.

Project status

BFSOS 0.9.0 is the current public release. The project continues to validate packages, installer/storage combinations, documentation, and maintainer workflows on the road to 1.0.

Release hosting: SourceForge hosts BFSOS ISO/base artifacts and this public website. GitHub remains authoritative for source code, ports, pull requests, and bug reports.
